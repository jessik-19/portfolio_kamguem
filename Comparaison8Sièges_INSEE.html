Application – Comparaison des Sièges INSEE

🎯 Objectif :
Concevoir une application permettant de comparer les informations de siège entre les bases internes et les données INSEE, afin de détecter les incohérences de nom, ville ou code établissement.

🚀 Particularité :
L’application réalise un matching intelligent entre les fichiers Excel internes et les correspondances INSEE, identifie les écarts ligne par ligne, puis génère automatiquement un fichier de synthèse. Elle met aussi en évidence les doublons et les cas à surveiller.

📊 Indicateurs & Analyses générées :
- Taux de correspondance des sièges
- Nombre d’écarts détectés (nom / ville / code)
- Cas de doublons / adresses multiples
- Liste des établissements non retrouvés
- Matching ville INSEE / ville interne (avec taux de similarité)
- Résumé des cas à revoir manuellement

🛠 Outils & Technologies :
Python (pandas, difflib), Streamlit, Excel, nettoyage des adresses, recherche floue, logique de matching, visualisation des résultats.

🔒 IMPORTANT :
Aucun identifiant sensible n’est affiché. L'application utilise des extraits de tests anonymisés. Code disponible sur GitHub.
