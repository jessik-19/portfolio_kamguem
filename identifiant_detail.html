Vérification des Identifiants Grand Back

🎯 Objectif :
Automatiser la vérification des identifiants attendus pour chaque utilisateur d’une équipe, en comparant les données issues de trois fichiers (périmètre, back, affectations).

🚀 Particularités :
✓ Interface intuitive développée avec Streamlit
✓ Détection automatique des identifiants manquants par utilisateur
✓ Résumé global avec calcul du nombre total d’identifiants manquants
✓ Téléchargement Excel généré automatiquement avec deux feuilles (vue globale & vue détaillée)
✓ Design professionnel (logo, couleurs Accor, mise en forme lisible)

📊 Indicateurs clés :
- Nombre total d’utilisateurs
- Nombre d’identifiants manquants par personne
- Liste des identifiants non attribués
- Taux de couverture des affectations

🛠 Technologies utilisées :
Python (Pandas), Streamlit, ExcelWriter, CSS personnalisé
